# Karyix

Karyix is a RESTful backend API for collaborative project management. It 
handles projects, tasks, subtasks, and notes with role-based access control 
(Admin / Project Admin / Member), giving teams a secure and structured way 
to manage work together.

## Features
- 🔐 JWT authentication with email verification and password reset
- 👥 Role-based access control (Admin, Project Admin, Member)
- 📁 Project CRUD and team member management
- ✅ Task management with status tracking (Todo / In Progress / Done)
- 📎 File attachments on tasks
- 🗂️ Subtasks and project notes
- ⚡ RESTful API design

## Tech Stack
Node.js · Express.js · MongoDB

> Note: Frontend is currently in progress.
